# TicketSmart

Уеб-базирана система за управление на вътрешни заявки за поддръжка в кредитна институция. Разработена е като приложение към дипломна работа „Уеб-базирана система за управление на вътрешни заявки за поддръжка в кредитна институция – TicketSmart“.

Системата събира заявките, отговорностите и сроковете на едно място. Тя разпределя автоматично заявките между агентите, като отчита натовареността, специализацията и отсъствията им, и показва на ръководителя KPI показатели за качеството на работата.

## Основни възможности

- **Три роли** – потребител (заявител), агент и администратор, с права, проверявани едновременно в интерфейса и на сървъра.
- **Автоматично разпределение на заявките** – по претеглена натовареност (теглото зависи от приоритета и срока по SLA), със специализация на агента и стабилно подреждане при равенство. Агентите с одобрено отсъствие се изключват.
- **Предложения за категория по заглавие** – офлайн алгоритъм без външно API (токенизация, премахване на стоп-думи, съкращаване на думите до корен и тегла по IDF принцип).
- **Жизнен цикъл на тикета** – Open → InProgress → Closed, с повторно отваряне (Reopened) от заявителя.
- **Управление на отсъствия** – заявка от агент, одобрение или отхвърляне от администратор, анулиране, календарен изглед.
- **KPI табло и експорт в Excel** – решени тикети, средна оценка, средно време за затваряне и процент спазен SLA срок, експорт в `.xlsx` с два листа.
- **Коментари, обратна връзка и прикачени файлове** – файловете се пазят в базата и остават след затваряне на тикета за проследимост.
- **Нотификации** в приложението и филтри на списъка с тикети.
- **Сигурност** – пароли с BCrypt, сесия с `HttpOnly` бисквитка, ограничение до 5 опита за вход в минута на IP адрес.

## Технологии

| Област | Избор |
|---|---|
| Сървър | ASP.NET Core 8 (Minimal API) |
| База данни | PostgreSQL 16 и Entity Framework Core 8 (code-first миграции) |
| Клиент | HTML, CSS и JavaScript, без framework |
| Пароли | BCrypt.Net-Next |
| Excel експорт | ClosedXML |
| Тестове | xUnit |

## Как се стартира

Нужни са [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) и PostgreSQL 16. Най-лесно се стартира с Docker.

1. Стартирай базата данни (ползва порт 5432):

   ```
   bash
   docker compose up -d
   ```

2. Стартирай приложението:

   ```
   bash
   dotnet run
   ```

3. Отвори <http://localhost:5080>.

При първо стартиране приложението само прилага миграциите и зарежда демонстрационни данни.

Ако не ползваш Docker, създай PostgreSQL база `ticketsmart` с потребител `ticketsmart` и парола `ticketsmart`, или задай своя връзка към базата чрез променливата на средата:


```
bash
ConnectionStrings__Default="Host=localhost;Port=5432;Database=ticketsmart;Username=...;Password=..."
```

В PowerShell: `$env:ConnectionStrings__Default = "Host=localhost;Port=5432;Database=ticketsmart;Username=...;Password=..."`.

## Тестове

```
bash
dotnet test
```

Проектът съдържа 51 автоматизирани теста за чистата бизнес логика: разпределение на тикети, предложения за категория, KPI изчисления, валидация на прикачени файлове и изчисляване на крайния срок. Тестовете не изискват база данни.

wwwroot/                 клиентска част (index.html, styles.css, app.js)
